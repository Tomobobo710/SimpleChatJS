API Configuration

System Prompts

Configure system instructions that guide AI behavior across all conversations. Applied automatically to the first message in each conversation.

This prompt will be automatically added to the beginning of new conversations with all AI providers.

Context toggles

Appends environment info (platform, working directory, shell, date) to the system prompt. The working directory only affects freeform chats — project chats use the project root.

Compaction Prompt

The instructions sent to the AI when compacting a chat (via /compact or auto-compact). SimpleChat wraps this with a "summarize the conversation" line and the conversation history — you're editing the template/rules in between. Leave it blank to use the built-in default.

Anthropic (Claude) Thinking

Extended reasoning for Claude models. Choose the mode that matches your model generation.

8192

Range: 1024–32000 tokens. Must be less than max_tokens.

Google (Gemini) Thinking

Controls Gemini's internal reasoning. Choose the API mode that matches your model generation.

8192

Range: 128–32768. Use 0 to disable (Flash only), -1 for auto.

Gemini 3 Pro only supports low and high (not medium).

llama-server Thinking

Controls reasoning token allocation per request. Works with DeepSeek-R1, QwQ, Qwen3, and other reasoning-capable models.

Auto

How reasoning tokens are returned. Use "DeepSeek" to get thinking blocks in the UI.

OpenAI Reasoning

Sets reasoning effort for o-series and GPT-5 models. Has no effect on non-reasoning models.

Sent as reasoning_effort in the Chat Completions API.

Display

Controls the thinking dropdown's auto expand/collapse behavior, same as tool dropdowns.

SimpleTools

Built-in tools available to the AI. These run natively without external servers.

read_file Read a UTF-8 text file and return its content
write_file Create or overwrite a file with given content
edit_file Replace exact string in an existing file
shell_run Run a shell command and return output
Caps read_file output; shell_run uses 1 KB less to leave room for its truncation notice. Min 2.

Shell

Select the shell for shell_run. "Auto" detects the best available shell on save.

Commands are killed if they run longer than this. The AI can override it per-call with timeout_sec.

Background Jobs

Lets shell_run run in the background (background:true) instead of blocking for completion — for long builds, dev servers, or watch tasks. The AI can list, poll, and kill its own background jobs (job_list/job_output/job_kill); you can always see and kill any job from the Processes panel regardless.

0 = no limit. A background job is meant to run long, so this is off by default — set it if you want a safety net.

Oldest output is dropped once a job's live buffer exceeds this, so a long-running/chatty job can't grow memory unbounded.

Browser Tool

Lets the AI open and drive real (hidden) browser tabs — navigate, read page text, click, type, screenshot, read console output. You can always see, reveal, or close any tab from the Web Tabs panel regardless of what the AI is doing.

Lets the AI run arbitrary JavaScript in a tab's page — a full escape hatch beyond the narrow click/type/read tools, for automating your own app or page. Turn off for a more restricted, sandboxed browser tool.

When on, a tab's timers/animation frames keep running at full rate even while hidden, instead of Chromium's usual power-saving throttle for unfocused windows.

Cache Control

When locked, the AI isn't even offered a tool to change cache behavior — the option above is enforced for every tab it opens, with no way for it to ask otherwise.

Screenshot Compression

Two independent knobs. Max resolution controls vision-model token cost directly (a bigger image costs more tokens regardless of file size) — pick the option matching your model, or set Custom. Max file size only bounds request/storage size; it has little effect on token cost by itself.

Tab Dimensions

The real page size (in pixels) every browser tab opens at — this is the coordinate space browser_click uses, separate from the screenshot resolution above. Larger tabs show more of a page at once but take longer to render; smaller tabs are faster but may cut off content.

When locked, browser_open's width/height parameters are removed from the AI's tool entirely — every tab always opens at the size set above, with no way for the AI to ask for a different one.

Checkpoints

For project-scoped chats, creates a snapshot of your project folder before and after every AI turn so you can restore it later from that turn's Checkpoint button in the chat. This can use a significant amount of disk space over time, especially on large projects — disable if you don't need it.

Checkpoints require git to be installed and available on your system PATH. Git wasn't found, so checkpoints are disabled until it's installed — see git-scm.com/downloads.

Patterns are written to the checkpoint repo's own git exclude file — never touches your project's .gitignore. Applies to new/changed checkpoints going forward.

Context Compaction

Compaction shrinks a long conversation so it keeps fitting in the model's context window: older turns are replaced with an AI-written summary, while recent turns are kept verbatim. You can compact any chat on demand with the /compact command in the message box.

When a request fails because it exceeded the model's context limit, automatically compact this chat, then retry the request once.

When you compact, the most recent turns are kept verbatim and everything older is folded into the summary. Keeps up to this many turns (fewer if the chat is shorter). Set to 0 to keep none. Default 4.

Display

After a compaction summary finishes streaming, its dropdown auto-collapses after this many seconds. Set to 0 to keep it open.

Image Compression

Controls how uploaded and pasted images are compressed before being sent to the model. Two independent knobs, same as the browser tool's screenshot compression: max resolution caps pixel dimensions (which drives vision-model token cost), max file size bounds request/storage size via a JPEG quality/scale ladder.
